## 1. Hiện trạng CCL-CMES

### 1.1 Codebase

- **Stack:** .NET 10 (target `net10.0`) · ASP.NET Core · **Blazor Server** ·
  EF Core 10.0.8 · Swagger · SignalR. Đây là khung MES MVP đã chạy được
  bằng `dotnet run`.
- **Clean Architecture, 4 project:**
  - `CCL.MES.Domain` — Entities + Enums + `WorkOrderStateMachine` (7 bước).
  - `CCL.MES.Application` — Services (WO/Spec/QC/OEE/WI/NPI), DTOs,
    `IMesDbContext`.
  - `CCL.MES.Infrastructure` — `MesDbContext`, `DbSeeder`, DI.

    `ShopfloorHub`.

  `/workinstructions`, `/npi/{engineer-routine|engineer-structure|engineer-spec|raw-materials|workcenter}`,

## 2. Pattern trích từ Ops Control v1.2 (read-only)

### 2.1 Bộ chọn ngôn ngữ bằng icon lá cờ

- **Component:** `client/src/components/Shared/LangFlagToggle.jsx` +
  `.css`.
- **Cấu trúc:** 2 button `<button>` trong `<div role="group">`, mỗi
  button có:
  - `aria-pressed` = (locale đang chọn?)
  - `aria-label` + `title` = tên ngôn ngữ ("English", "Tiếng Việt")
  - `<span class="lang-flag-emoji">🇬🇧</span>` (Ops Control hiện dùng
    **emoji cờ Unicode** chứ không phải SVG)
  - `<span class="lang-flag-code">EN</span>` / `VN`
- **Hook switch:** `useI18n()` trả về `{ locale, setLocale, t }`. Click
  cờ → gọi `setLocale('en'|'vi')`.
- **Persist:** `localStorage.setItem('ops_locale', next)`. Auto-detect
  lần đầu từ `navigator.language`.
- **Vị trí dùng:** không xuất hiện trong LoginPage; chỉ có ở
  `HardwareSection` + `ModeSection` (Settings sub-tab). Trên login có
  hàm `localiseAuthError()` dùng `t()` để dịch lỗi.

> **Lưu ý cho CCL-CMES:** anh yêu cầu **dùng SVG flag để đồng nhất
> giữa OS** (emoji có thể render khác trên Windows/macOS/Linux). Ta sẽ
> KHÔNG copy y nguyên emoji của Ops Control mà thay bằng SVG inline.

### 2.2 Hook i18n

- **File:** `client/src/utils/useI18n.js` (70 LOC).
- **Bảng từ vựng:** `client/src/i18n/strings.js` — flat key
  `STRINGS['nav.dashboard'] = { en, vi }`. 293 dòng, alphabetised
  trong từng section.
- **Fallback chain:** locale chỉ định → tiếng Anh → key thô (để dev
  spot key thiếu).
- **`SUPPORTED_LOCALES = ['en', 'vi']` + `DEFAULT_LOCALE = 'en'`.**

### 2.3 Settings + sub-tab list (NGUỒN để nhân bản y hệt)

File: `client/src/modules/cost/tabs/Settings.jsx` (3040 LOC, có
`MENU_SECTIONS` ở dòng 25–57).

**Cấu trúc 3 nhóm × 10 mục (đúng thứ tự, đúng tên gốc):**

| # | Group | id | Icon | Label hiển thị | minRole | Ghi chú |

### 3.4 Auth / i18n / Settings (mới hoàn toàn)

#### a. i18n (Phase 2 dựng nền)

**Khuyến nghị approach:**
- Dùng **ASP.NET Core Localization built-in** (`IStringLocalizer<T>`)
  + `RequestLocalizationOptions` với culture cookie
  `.AspNetCore.Culture`.
- Resource file: `Resources/Shared.en.resx` + `Resources/Shared.vi.resx`.
  Truy cập trong Razor: `@inject IStringLocalizer<SharedResource>
  Loc` → `Loc["nav.home"]`.
- Switch ngôn ngữ: hook serverside `HttpContext.Response.Cookies.Append`
  + `Response.Redirect(currentUrl)` để culture được áp dụng ngay round
  tiếp theo. Persist cookie 1 năm.
- Tên file resource tham chiếu chính tả tương đương `STRINGS` của Ops
  Control (`nav.home`, `settings.title`, `login.username`...).

> **Lý do KHÔNG dùng `localStorage` như Ops Control:** Blazor Server
> render server-side; switch ngôn ngữ qua cookie là pattern chuẩn
> .NET, dễ test, không cần re-render Blazor circuit.

#### b. Login (Phase 2)

**Khuyến nghị approach:**
- ASP.NET Core **Cookie Authentication** (không Identity DB phức tạp ở
  Phase 2 — chỉ cần login page chạy + persist + i18n).
- Entity mới: `User` (Id, Username, PasswordHash, Role, Locale).
- Hash: `Microsoft.AspNetCore.Identity.PasswordHasher<User>` (PBKDF2
  built-in, không cần lib ngoài).
- Trang: `/login` (Razor Page hoặc Blazor) hiển thị form +
  `LangFlagPicker` ở góc trên. Click cờ → POST `/setlang` → set cookie
  → reload `/login` với culture mới.
- Persist sau login: cookie `OpsControl.Auth` (Sliding expiration 8h).
- Seed user mặc định khi DB tạo lần đầu: `admin` / `admin123` + locale
  `vi` (để demo).

**Component cờ lá quốc kỳ (SVG, đa OS):**
- Tạo `Shared/LangFlagPicker.razor` + 2 SVG inline cho VN (cờ đỏ sao
  vàng) + GB (Union Jack) **hoặc** US (sao sọc). **Cần anh chọn GB hay
  US.** Đề xuất: **GB**, lý do — code chuẩn ISO `en-GB` thường gắn với
  cờ Union Jack; dễ phân biệt với cờ Mỹ trên thị trường ASEAN; không
  liên quan chính trị.
- A11y: mỗi nút có `aria-label="English"` / `aria-label="Tiếng Việt"`
  + tooltip; viền focus rõ.

#### c. Settings dropdown (Phase 3)

**Khuyến nghị approach:**
- Thêm dropdown thứ 3 vào `MainLayout.razor` topbar (cạnh
  `NPI Data ▾` và `QC/QA Data ▾`), label "Setting".
- 10 sub-tab y hệt bảng §2.3 (id, icon, nhãn, thứ tự).
- Vì auth Phase 2 mới chỉ login + persist (chưa có RBAC), Phase 3
