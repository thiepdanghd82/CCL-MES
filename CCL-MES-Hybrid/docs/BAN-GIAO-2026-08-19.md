### 2. WAL — `shasum` trên riêng `.db` KHÔNG phải dấu vân tay

`journal_mode = wal`. Khi API đang chạy, dữ liệu mới nằm trong `ccl_mes.db-wal`.
Gặp thật: ghi 12 dòng xong mà SHA file chính **không đổi một bit**.

```bash
sqlite3 data/ccl_mes.db "PRAGMA wal_checkpoint(TRUNCATE);"   # 0|0|0 = xong
shasum -a 256 data/ccl_mes.db
```
Sao lưu bằng `sqlite3 ".backup"` hoặc `VACUUM INTO` từ connection `mode=ro`.
**KHÔNG dùng `cp`** — bỏ sót WAL, đã làm hỏng một bản copy khi điều tra.

## Tiến trình đang chạy

| | |
|---|---|
| API | cổng 5100, `data/ccl_mes.db`, log `/tmp/ccl-api-5100.log` |
| App MAUI | bundle `CCL-MES-Hybrid/src/CCL.MES.Hybrid/bin/Debug/net10.0-maccatalyst/maccatalyst-arm64/CCL MES.app` |

Khởi động lại API:
```bash
cd "…/CCL-MES/CCL-MES-Hybrid/src/CCL.MES.Api"
MES_DB_PATH="…/CCL-MES/data/ccl_mes.db" ASPNETCORE_URLS="http://localhost:5100" \
  nohup ./bin/Debug/net10.0/CCL.MES.Api > /tmp/ccl-api-5100.log 2>&1 &
```
Build app MAUI cần cờ này (Xcode 26.6 vs SDK mong 26.5):
```bash
dotnet build CCL-MES-Hybrid/src/CCL.MES.Hybrid/CCL.MES.Hybrid.csproj \
  -c Debug -f net10.0-maccatalyst -p:ValidateXcodeVersion=false
```
⚠ Khi tắt tiến trình, **lọc theo PID chính xác**. Lọc chuỗi `CCL.MES.Hybrid` cũng
khớp đường dẫn của API (`CCL-MES-Hybrid/src/CCL.MES.Api`) — đã tắt nhầm API một
lần vì lỗi này.
