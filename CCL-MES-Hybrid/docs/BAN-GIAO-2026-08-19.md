### 2. WAL — `shasum` trên riêng `.db` KHÔNG phải dấu vân tay

`journal_mode = wal`. Khi API đang chạy, dữ liệu mới nằm trong `ccl_mes.db-wal`.
Gặp thật: ghi 12 dòng xong mà SHA file chính **không đổi một bit**.

```bash
sqlite3 data/ccl_mes.db "PRAGMA wal_checkpoint(TRUNCATE);"   # 0|0|0 = xong
shasum -a 256 data/ccl_mes.db
```
Sao lưu bằng `sqlite3 ".backup"` hoặc `VACUUM INTO` từ connection `mode=ro`.
**KHÔNG dùng `cp`** — bỏ sót WAL, đã làm hỏng một bản copy khi điều tra.
