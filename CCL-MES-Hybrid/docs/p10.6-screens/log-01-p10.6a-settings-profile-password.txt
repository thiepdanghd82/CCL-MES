--- [7] POST /password — wrong current pwd ---

HTTP 422
Body: { "code": "auth.wrong_current",
        "messageEn": "Current password is incorrect." }

--- [8] POST /password — new pwd < 4 chars ---
Request: { "currentPassword": "P@ss!1", "newPassword": "abc" }
HTTP 422
Body: { "code": "auth.new_too_short",
        "messageEn": "New password must be at least 4 characters." }

--- [9] POST /password — blank fields ---
Request: { "currentPassword": "", "newPassword": "WHATEVER" }
HTTP 422
Body: { "code": "auth.missing_fields",
        "messageEn": "Both current and new password are required." }

--- [11] POST /password — clears MustChangePassword flag ---

current → MustChangePassword flips to false (Phase 6 Bước 4 mirror).
